# Designing for Trust in Agentic AI
## A Framework for Product Designers

**Duration:** 15-20 minutes
**Audience:** Product designers familiar with AI

---

## Visual Design System (Trust-Optimized)

**Color Palette (Research-Backed for Trust):**
- Primary Background: Off-white / light gray (#FAFAFA, #F5F5F5)
- Primary Accent: Mid-blue (#2196F3) - proven most trustworthy in studies
- Secondary: Muted teal (#00897B) - stability, competence
- Confirmation: Soft green (#66BB6A) - success states only
- CTA Accent: Soft warm orange (#FF7043) - single warm accent for primary actions
- Text: Charcoal Gray (#37474F) - high contrast, readable
- Warnings: Red reserved ONLY for errors/warnings - never decorative

**Visual Style (Evidence-Based):**
- Clean, professional, calm, coherent, intentional design
- Strong grid alignment, stable visual hierarchy, ample whitespace
- Rounded corners on cards and buttons (increases perceived warmth)
- Generous spacing, few competing focal points
- Consistent iconography (same line weight, radius)
- Human silhouettes interacting with abstract AI forms

### The Shift is Happening

AI agents are becoming **colleagues, not just tools**.

They're drafting your emails, managing your calendar, writing your code, and making decisions on your behalf. This is a fundamental shift in how humans interact with software.

### The Trust Paradox

| More Capable | = | More Risk | = | More Need for Trust |
|--------------|---|-----------|---|---------------------|
| Agents can do more | | Mistakes have bigger impact | | Users need confidence to delegate |

**The uncomfortable truth:** Users will abandon powerful AI systems they don't trust faster than they'll abandon limited ones they do.

### What Breaks Trust?

- **Opacity** — "I don't know what it's doing"
- **Unpredictability** — "I can't anticipate its behavior"
- **Loss of control** — "I can't stop it or change course"
- **Hidden failures** — "It was wrong and I didn't know"

> **Speaker Note:** Open with a personal story or industry example of AI trust failure. The goal is to make this visceral, not abstract.

### 1. Delegation Modes (Category 1: Role Clarity)

**The Pattern:** Give users explicit control over how much autonomy the agent has.

| Mode | Agent Behavior | User Role |
|------|----------------|-----------|
| **Advisor** | Suggests only | User does everything |
| **Co-Pilot** | Drafts & proposes | User approves before action |
| **Autopilot** | Executes within guardrails | User monitors & intervenes |

**Why It Builds Trust:**
- Users choose their comfort level
- Expectations are explicit, not assumed
- Easy to dial back if confidence drops

**Example:** A support agent starts in Advisor mode for new users, suggesting responses. As users gain confidence, they can switch to Co-Pilot (agent drafts, user approves) or Autopilot (agent sends low-risk responses automatically).

> **Speaker Note:** This is foundational. If users don't know what the agent CAN do, they can't trust what it WILL do.

### 2. Kill Switch, Pause & Resume + HITL Gates (Category 3: Control)

**The Pattern:** Users can halt, pause, or require approval for agent actions at any time.

**Kill Switch Components:**
- **Pause** — Stop execution, preserve state, resume later
- **Stop** — Cancel entirely with graceful cleanup
- **Resume** — Continue from checkpoint with optional adjustments

**Human-in-the-Loop (HITL) Gates:**
- Critical actions blocked until human approves
- Clear preview of what will happen
- Batch approve, session approve, or rule-based options

**Why It Builds Trust:**
- Users never feel trapped
- High-stakes actions require explicit consent
- Mistakes are recoverable

**Example:**
```
┌──────────────────────────────────────────────────┐
│  🚨 Approval Required                            │
│                                                  │
│  Campaign will send to 3,214 customers           │
│                                                  │
│  Preview: "Hi {name}, your renewal is due..."    │
│                                                  │
│  [View Full List]  [Approve]  [Reject]  [Edit]   │
└──────────────────────────────────────────────────┘
```

> **Speaker Note:** This is the "seatbelt" of agentic AI. Users will take more risks when they know they have an emergency brake.

### 3. Reasoning Glimpse — Chain of Thought (Category 5: Transparency)

**The Pattern:** Show users a concise, human-readable plan of how the agent approaches a request.

**Components:**
- Step-by-step plan (3-7 steps typically)
- Live progress indicators as steps execute
- Tool/data source labels for each step
- Expandable detailed trace for power users

**Why It Builds Trust:**
- Transforms "black box" into visible reasoning
- Users can catch errors before they propagate
- Builds confidence through demonstrated competence

**Example:**
```
┌──────────────────────────────────────────────────┐
│  📋 Analyzing compliance requirements            │
│                                                  │
│  ✓ 1. Identify relevant regulations              │
│  ✓ 2. Extract key clauses from policy docs       │
│  → 3. Compare against current practices          │
│  ○ 4. Draft recommendations                      │
│  ○ 5. Generate summary report                    │
│                                                  │
│  [Expand Details]                                │
└──────────────────────────────────────────────────┘
```

> **Speaker Note:** "Show your work" isn't just for math class. When AI shows its reasoning, users can verify it's on the right track—or steer it before it's too late.

### 4. Confidence Thermometer (Category 6: Uncertainty)

**The Pattern:** Visually communicate the agent's confidence level with supporting context.

**Components:**
- Visual confidence meter (e.g., 5-bar scale)
- Expandable reasoning for the confidence level
- Supporting factors and warning flags
- Recovery actions when confidence is low

**Why It Builds Trust:**
- AI admits what it doesn't know
- Users can calibrate their own trust appropriately
- Low confidence triggers appropriate caution

**Example:**
```
┌──────────────────────────────────────────────────┐
│  Pipeline Forecast: $2.4M                        │
│                                                  │
│  Confidence: ████░  High                         │
│                                                  │
│  ▼ Supporting Factors                            │
│    • Based on 847 historical deals               │
│    • Seasonal patterns match expectations        │
│    ⚠️ 3 deals missing close dates                │
│                                                  │
│  [View Details]  [Recalculate]                   │
```

> **Speaker Note:** Overconfident AI is dangerous AI. The best way to build trust is to be honest about uncertainty.
